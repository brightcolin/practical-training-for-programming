# Homework 4: Qt Signals and Slots

- [QtKeypad](QtKeypad/): numeric buttons, QSignalMapper, a display field, and a clear button.
- [TemperatureConverter](TemperatureConverter/): QObject signals and slots synchronize Celsius and Fahrenheit controls.

Open each directory's `CMakeLists.txt` in Qt Creator. Select a Desktop Kit with Qt 6.5 or later, then build and run.
