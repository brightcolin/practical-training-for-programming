# Homework 5: Qt Event Handling

[EventFilter](EventFilter/) installs an event filter on the input field. Pressing Return or Enter appends nonempty text to a read-only output area, clears the input field, and consumes the key event.

Open `EventFilter/CMakeLists.txt` in Qt Creator. Select a Desktop Kit with Qt 6.5 or later, then build and run.
