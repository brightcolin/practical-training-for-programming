# 时间修补局：编译与运行

## Qt Creator

1. 安装 Qt 6.5.3 或兼容的 Qt 6 Desktop Kit，并准备支持 C++17 的编译器。
2. 打开 `src/TimeRepairBureau.pro`。
3. 选择已配置好的 Desktop Kit，使用 Release 配置构建。
4. 将 `src/assets/` 和 `src/config/` 复制到可执行文件同级，文件夹名称保持为 `assets` 和 `config`。公开仓库没有附带 WAV 文件，缺少音频时对应声音静音。
5. 在 Qt Creator 中运行，或部署依赖后从输出目录运行。

原项目使用 Windows 与 Qt 6.5.3 MinGW 64-bit。声音实现包含 Windows 专用分支，其他平台的声音行为需要单独验证。

## 命令行参考

在与 Qt Kit 对应的开发者终端中，先进入本项目目录：

```powershell
New-Item -ItemType Directory -Force build | Out-Null
Set-Location build
qmake ../src/TimeRepairBureau.pro -spec win32-g++ CONFIG+=release
mingw32-make
Copy-Item ../src/assets ./release/assets -Recurse -Force
Copy-Item ../src/config ./release/config -Recurse -Force
windeployqt ./release/TimeRepairBureau.exe
./release/TimeRepairBureau.exe
```

以上命令假设 qmake、MinGW make 和 windeployqt 来自同一 Qt Kit，并且该 Kit 使用标准的 `release/` 输出目录。若输出位置不同，将素材和 Qt 依赖部署到实际可执行文件所在目录。

## 运行数据

程序会在可执行文件附近创建 `data/` 保存进度、设置和编辑器地图。这些运行数据已加入 `.gitignore`，不属于源码归档。
