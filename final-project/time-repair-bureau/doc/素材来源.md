# 素材来源

> GitHub 归档说明（2026-10-06）：下文描述原课程提交版本的素材。本次公开仓库收录图片，暂未上传 18 个 Pixabay WAV 文件；原始音频保留本地。逐项音频的下载链接与许可记录尚未包含在原资料中。

当前版本主要使用 Qt / QPainter 绘制图形界面、网格、塔、敌人、子弹、状态效果和 UI 元素，并加入少量 AI 生成位图素材提升整体观感。

视觉升级后的背景光效、HUD 面板、地图格、路线发光、防御塔图形、敌人图形、子弹拖尾、状态效果等均为代码绘制，不涉及第三方素材授权。

## AI 生成素材

生成工具：Codex 内置图像生成工具。

素材文件：

- `src/assets/ai/bg-main.png`：开始界面、关卡选择界面、游戏背景。
- `src/assets/ai/bg-victory.png`：胜利结果界面背景。
- `src/assets/ai/bg-failure.png`：失败结果界面背景。
- `src/assets/ai/bg-archive.png`：剧情档案、游戏说明、时间图鉴页面背景。
- `src/assets/ai/sheet-towers.png`：6 类防御塔资产板源图。
- `src/assets/ai/sheet-enemies.png`：6 类敌人资产板源图。
- `src/assets/ai/sheet-enemies-v2.png`：6 类敌人新版资产板源图，用于提升战斗可读性和主题辨识度。
- `src/assets/ai/sheet-operators.png`：3 位通讯角色头像资产板，用于关卡前后剧情对话。
- `src/assets/ai/sheet-tiles.png`：6 类地形/路径视觉资产板源图。
- `src/assets/ai/tower-*.png`：由防御塔资产板切分并抠图得到的透明防御塔图标。
- `src/assets/ai/enemy-*.png`：由敌人资产板切分并抠图得到的透明敌人图标。
- `src/assets/ai/enemy-*-v2.png`：由新版敌人资产板切分并抠图得到的透明敌人图标，游戏优先加载新版，失败时回退旧版。
- `src/assets/ai/tile-*.png`：由地形资产板切分并抠图得到的透明地形叠层图标。

生成要求：

- 时间修补局主题。
- 科幻钟表机械风格。
- 蓝金色主色调。
- 无文字、无 logo、无水印。
- 档案背景额外要求为时间档案室/控制中枢场景，方便叠加说明文字面板。
- 通讯角色头像额外要求为三联画构图，包含局长、导航员和监测 AI，风格统一且无文字。

后处理说明：

- 使用本地脚本 `tools/extract_ai_icons.py` 从资产板中切出单个图标。
- 对资产板暗色背景进行透明化处理。
- 对新版敌人资产板的绿色抠图背景进行透明化处理，并去除边缘绿色溢色。
- 对地形资产板的绿色抠图背景进行透明化处理，并作为地图格子的半透明叠层使用。
- 对图标主体进行居中裁切。
- 对因果切割器图标移除过长的静态光束，游戏中改由程序动态绘制光束。

## 音效素材

当前版本包含 18 个 WAV 音频文件。早期版本由项目内脚本 `tools/generate_sfx.py` 使用正弦波、三角波、软方波、低频噪声、包络、混音和低频脉冲算法生成；当前提交前已由作者从 Pixabay 下载自选音频，转换为同名 WAV 并放入 `src/assets/sfx/`，游戏继续通过同一套文件名加载。

音效文件：

- `src/assets/sfx/ui-click.wav`：按钮与通讯推进。
- `src/assets/sfx/terminal-boot.wav`：接入终端界面启动与线路唤醒。
- `src/assets/sfx/dialogue-blip.wav`：通讯文字逐字出现。
- `src/assets/sfx/mission-start.wav`：任务投影结束、波次展开。
- `src/assets/sfx/build.wav`：部署防御塔。
- `src/assets/sfx/upgrade.wav`：升级防御塔。
- `src/assets/sfx/freeze.wav`：释放时序冻结。
- `src/assets/sfx/boss-alert.wav`：Boss 出现警报。
- `src/assets/sfx/boss-stinger.wav`：Boss 入场冲击音。
- `src/assets/sfx/error-deny.wav`：资源不足、不能建造、未授权等拒绝反馈。
- `src/assets/sfx/core-damage.wav`：异常体突破核心时的受损警报。
- `src/assets/sfx/codex-unlock.wav`：新敌情识别、新装置授权写入图鉴。
- `src/assets/sfx/victory.wav`：胜利结算。
- `src/assets/sfx/failure.wav`：失败结算。
- `src/assets/sfx/ambience-menu.wav`：主菜单、档案、设置页的低音量终端环境音。
- `src/assets/sfx/ambience-battle.wav`：战斗中的循环背景音乐 / 时域压力环境音，已替换为作者新选的 Pixabay 音源。
- `src/assets/sfx/story-bgm.wav`：序幕、关卡前后通讯、失败回溯通讯背景音乐。
- `src/assets/sfx/boss-bgm.wav`：Boss 波背景音乐。

原提交资料注明上述音频来自 Pixabay，已转换为 WAV 并用于课程作业展示。原资料给出的许可页面为 https://pixabay.com/service/license-summary/ 。本次归档没有逐项音频的下载链接和许可凭据，因此没有将 WAV 文件加入公开仓库，也没有独立验证每个音频的公开分发条件。
