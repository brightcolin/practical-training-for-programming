# 音频资源

声音管理模块从可执行文件同级的 `assets/sfx/` 读取 WAV 文件。文件缺失时，对应音效或音乐静音。

## 资源分类

- 界面：点击、终端启动、对话和错误反馈。
- 战斗：部署、升级、技能、Boss 和核心受损。
- 结算：胜利、失败和图鉴解锁。
- 音乐：菜单、战斗、剧情和 Boss 曲目。

文件名与用途见 [素材说明](../../../doc/素材来源.md) 和 qmake 工程的 DISTFILES 清单。

## 部署

将 WAV 文件放入此目录，构建后将整个 `assets/` 目录复制到可执行文件同级。音频资源应按各自许可证使用。
